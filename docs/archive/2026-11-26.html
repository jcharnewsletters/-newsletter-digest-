'Speculative Encoding' Cuts AI Agent Context Costs

  • Agents increasingly pass full context between models as text, and prefill costs (the initial processing pass) grow quadratically with context length.
  • Speculative encoding directly translates hidden states (internal model representations) between models instead of re-processing text, speeding up response startup while maintaining accuracy.
  • This eliminates redundant computation since the sending model already computed what the receiving model would otherwise recompute.
