Jev: A New AI Model for Fast, Cheap Binary Decisions

  • Jev, a new AI model from TypeSafe, makes binary software decisions (yes/no style choices) 200x faster and 400x cheaper than frontier large language models (LLMs, the big general-purpose AI models like GPT-4), enabling automation of tasks like PR (pull request, a proposed code change) reviews and support ticket triage.
  • Claude Code can use Jev to intelligently compact coding sessions by scoring which tool calls still matter, shrinking a 1M-token session (tokens are chunks of text an AI processes) to 86K tokens in one second without losing critical context.
  • Browser agents powered by Jev complete tasks like flight searches in 7 seconds for under a penny by having Jev pick clicks from a numbered menu of page elements instead of an LLM analyzing screenshots.
  • Setup: create a free API key at console.typesafe.ai (no waitlist), export it as TYPESAFE_API_KEY, then install TypeSafe's Claude Code plugin to build a custom document-scoring tool.
  • Compaction workflow: install the fast-jev-compaction plugin, enable function hooks in Claude Code settings, then run /compact to prune stale tool-call results while preserving essential context like coding rules.
  • Browser agent workflow: install Chrome, the Python tool 'uv', and an OpenRouter account (provides a small text-only backup model), then clone the jev-ultrafast repo and run 'uv run jev' to launch an agent that completed a Zürich-to-London flight search in 7.1 seconds for $0.0039.
