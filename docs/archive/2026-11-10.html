Testing local AI apps for hidden internet dependencies

  • Many open-source AI libraries silently download helper files on first use—such as tokenizers (text lookup tables that chop input into model-readable pieces), embedding models, or browser components—creating false assumptions about offline functionality.
  • Humanet tested 20 repositories with its airgap-check tool and found 9 of 10 tested repos had first-use downloads; the checker raised 4 false alarms and missed 5 individual downloaders.
  • Airgap-check scans code for downloaders and telemetry packages, runs smoke tests (quick functionality checks) in a sealed, network-disabled sandbox, and can generate a Dockerfile block to pre-download assets during image build instead of at runtime.
  • Clean results only vouch for tested paths; the tool is recommended before deploying AI tools on sensitive networks like hospitals or machines holding confidential data.
