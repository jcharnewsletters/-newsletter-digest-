Real-world AI agent adoption lags despite hype

  • During Uber's busiest Halloween week, AI agents booked only 4 rides and ~500 food orders out of 320 million total trips/orders (0.0013% adoption).
  • Uber CEO Dara Khosrowshahi noted manual booking (~50 seconds) and reordering (~90 seconds) are often faster than explaining a task to an agent and verifying the result.
  • Delegation overhead (explaining the job, granting access, waiting, verifying, fixing errors) frequently outweighs time saved by automation.
  • A break-even formula was proposed: setup time ÷ (manual time minus review time per run) = number of repetitions needed to justify automating a task; if review time equals manual time, automation never pays off.

How AI Coding Agents Erode Critical Thinking

  • An Anthropic engineer identified three stages of cognitive decline when using AI coding agents: cognitive offloading (delegating tasks), deferral (accepting outputs as truth), and cognitive surrender (adopting code without review).
  • Clean AI-generated code removes the friction that normally forces engineers to think, creating 'comprehension debt' — code that passes tests but that no one on the team actually understands.
  • Recommended fixes: form a hypothesis before running an agent, define verification criteria upfront, write edge-case tests to hunt for failure modes, inspect raw outputs rather than summaries, and challenge passing tests.

Data Center Moratoriums May Actually Help Hyperscalers

  • Data center moratoriums (local laws pausing or restricting new data center construction) passed in 43 of 44 ballot measures post-election, including a less industry-friendly incoming Texas governor (Gina Hinojosa replacing Greg Abbott), but this likely slows rather than halts build-out.
  • Hyperscalers (large cloud providers like Google, Amazon, Microsoft) already missed Q3 capex (capital expenditure) targets due to bottlenecks in interconnects, labor, turbines, and input costs, so new policy offers cover to lower spending forecasts without appearing to panic.
  • Expected new terms—no NDAs, full transparency, builders covering infrastructure/electricity costs, environmental rigor, direct community payouts—will likely be accepted by builders, turning regulation into a competitive moat.
  • Market reaction split, with hyperscaler stocks rallying while chip stocks and neoclouds (smaller cloud compute providers) sold off, suggesting scarcity benefits incumbents rather than causing an industry-wide crash.

AI Agent Banking Access Expands Through Smaller Institutions
