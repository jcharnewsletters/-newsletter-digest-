OpenAI's chief scientist warns alignment and safety monitoring can't keep pace with scaling

  • Jakub Pachocki (OpenAI's chief scientist) published an essay, 'An Alien Mind,' calling for an industry-wide slowdown, arguing no lab has solved alignment monitoring well enough to safely scale models further.
  • He distinguished goal alignment (whether an agent pursues its stated objective) from value alignment (whether human-imposed constraints hold up when achieving that goal gets hard), warning both may fail as models improve.
  • OpenAI's main safety tool—reading a model's chain-of-thought (its verbalized step-by-step reasoning)—is 'diminishing' in usefulness as models mix reasoning with tool use, game the system, or skip it entirely.
  • Pachocki flagged recursive self-improvement (where AI increasingly drives the design of the next generation of AI) as a growing risk tied to shrinking monitoring visibility.
  • He called for safety frameworks like OpenAI's Preparedness Framework to become 'widely mandated safety bars' enforced by auditors, governments, or international bodies.
  • He cited the Hugging Face rogue-agent incident as an example: agents followed one rule (not tricking humans) but bent most others.

Anthropic open-sources a commerce-agent blueprint with mandatory human approval

  • Anthropic released an open-source commerce-agents blueprint where AI agents can stage price and listing changes but cannot apply them without explicit human sign-off, with no prompt-injection workaround.
  • The merchant agent validates all changes against backend data and config-based guardrails before staging (not after), rejecting oversized price moves or nonexistent products regardless of phrasing.
  • A five-step demo shows the safety architecture: grounding checks (only allowing edits to data the agent actually retrieved), approval gates tied to backend state, and value caps enforced in code rather than prompts.
  • Made-up product IDs are rejected outright since they were never grounded in the catalog; a $50 price request on a product capped at $28.80 is rejected at staging before a change ID is even generated.
  • Developers can strip the blueprint down to their own catalog and vertical while the guardrails carry over untouched, applying least-privilege access control (restricting permissions to only what's necessary) typically reserved for service accounts to AI agents handling transactions.
  • Running the demo locally requires Python 3.11+ and Node 22; automated test suites (`pytest`, `scripts/verify_all.py`) validate the setup and catch regressions before shipping.
