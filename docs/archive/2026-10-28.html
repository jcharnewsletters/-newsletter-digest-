Google's Genie 4: Interactive AI Worlds with Sound

  • Genie 4 is a world model (AI that simulates an environment responding to user actions in real time, rather than generating a static video clip) producing photorealistic, interactive 3D environments.
  • Unlike Genie 3, it generates native audio—ambient sound, music, and character dialogue—synced with the visuals, and maintains scenes for up to 2 minutes (double the prior duration).
  • Users control exploration via keyboard and can edit scenes mid-session with text prompts while preserving visual coherence; it also simulates physics like object collisions.
  • A demo paired Genie 4 with Gemini to let an Apptronik Apollo humanoid robot play checkers inside a simulated world, pointing toward robot-training applications.
  • Key limitation: objects, physics, and spatial details remain inconsistent over longer sessions.
  • Access is limited to research testers, Google AI Ultra subscribers, and select API partners, rolling out soon.
