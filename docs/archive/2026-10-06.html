Ethereum Foundation launches zkAPI privacy protocol

  • zkAPI is a zero-knowledge protocol (a cryptographic method letting one party prove something is true without revealing the underlying data) enabling private API access without exposing user identity, usage patterns, or payment details to intermediaries.
  • Users deposit ETH into a vault, generate a zero-knowledge proof, and receive a fixed API access quota with no record linking usage back to the caller.
  • Payment metadata is abstracted at the protocol layer, closing a privacy gap that earlier AI inference payment schemes had leaked.
  • OA-chat is already integrated with zkAPI, and the design is intended to generalize to any gated API resource needing privacy, not just AI inference.

Reflection AI releases Beam, a new open-weight model competing with Chinese rivals

  • Reflection AI (a $25B startup founded by former DeepMind researchers) released Beam, an open-weight model (publicly available AI model weights that anyone can run or modify) for coding, reasoning, and agentic tasks (AI that autonomously takes actions toward goals).
  • Beam matches the performance of China's GLM-5.2 on reasoning and coding benchmarks while using 3-4x less computing power for training and deployment.
  • Architecture details: 501B total parameters with only 23B 'active' per query (a sparse model design where just a fraction of parameters activate per task), trained on 23.8 trillion tokens plus 100M+ reinforcement learning rollouts; open weights expected in October.
  • Released under Apache 2.0 license, letting companies run and customize it on their own chips and private data; a test deployment is reportedly underway in South Korea for government/hedge-fund 'AI factories.'
  • Beam beats other U.S. open models like Thinking Machines' Inkling but still lags behind top Chinese models like Moonshot's Kimi K3, joining Meta and Nvidia as rare Western labs with competitive open models.

OpenAI launches textGrain, an invisible watermark for ChatGPT/Codex text in the EU

  • textGrain embeds a hidden signal (readable only by a special detector) in ChatGPT and Codex outputs, satisfying new EU AI Act transparency/labeling requirements without affecting generation speed or quality.
  • Public detector tool is not available at launch; access is restricted to vetted researchers to limit false positives and reputational risk.
  • OpenAI explicitly states the watermark cannot prove authorship, reveal how much a human edited the text, or verify factual accuracy\u2014positioning it as compliance rather than an authenticity guarantee.
  • Deployment is EU-only and off by default elsewhere, contrasting with Anthropic's Claude watermark (built on Google's SynthID), which launched globally across all products.
  • The watermark has an exploitable weakness: rewriting just 10% of words drops detection accuracy from ~92% to 66%, and rewriting 25% drops it to just 17%; short passages and math text are hardest to detect (~80% vs ~95% for longer text).
