Adobe is opening Photoshop to your AI agent

  • Adobe is integrating AI agents deeper into its Creative Cloud suite, letting creators delegate multi-step tasks while retaining full control and editability over projects.
  • Adobe previewed local MCP (Model Context Protocol, a standard that lets third-party AI agents interact directly with an app's files) integrations for Photoshop, Illustrator, Premiere, and After Effects, launching in private beta early 2027.
  • Creative Agent gets a Plan Mode (lets users review and adjust an agent's proposed workflow before it runs) and a Model Selector (lets users choose which AI model executes a given task).
  • Always-on background agents will eventually handle recurring tasks without active user direction.
  • Keeping native project files editable after agent edits matters because AI outputs often need refinement, and pros require precise control for final delivery.
