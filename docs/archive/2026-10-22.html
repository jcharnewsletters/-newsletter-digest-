Building a Verified Browser Agent with Playwright and OpenAI

  • Author built a Python agent that navigates websites autonomously, searching for a Mark Twain quote containing 'truth' by breaking tasks into controlled, verified steps.
  • Architecture: model receives an ARIA snapshot (semantic page description using roles and accessible names) and proposes one of two actions (click a link or finish); Python code executes the validated action, looping up to 12 steps.
  • Setup requires pip install playwright openai pydantic, playwright install chromium, an OPENAI_API_KEY, and a model supporting Structured Outputs (enforced response format).
  • Verification layer checks exact quote text, confirms author, validates link existence, and tracks visited URLs to prevent loops\u2014catching five failure modes: invented quotes, wrong attribution, missing links, repeated pages, and unverified success.
  • Production advice: start with narrow, provably-successful tasks, add verification for every new capability, trim tokens on large pages, and use real sandboxing rather than simple path checks.
