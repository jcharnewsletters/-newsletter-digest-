Cloudflare's Clairic extraction model cuts AI inference costs

  • Cloudflare introduced Clairic, a new class of 'extraction models' that pull structured/typed values directly from messy, unstructured data in a single forward pass (rather than generating new text like a traditional LLM).
  • Clairic returns null when a value isn't present, avoiding the hallucination problem where LLMs invent false information.
  • Paired with an LLM for cleanup, the approach was 3.2x faster and 49% cheaper than using an LLM alone to parse messy inputs.
  • Separately, Cloudflare cut its own average AI inference cost from $2.43 to $0.77 per request (68% savings) by optimizing message ordering across sessions to maximize cache hits and minimize redundant computation.
  • Clairic works alongside Clef, a companion decision model, to give agents cleaner data before processing.

The 'Gauntlet Loop' Technique for Self-Improving AI Agents

  • Agents typically produce a reasonable first attempt then stop, over-rating their own output like students grading their own exams when asked to improve it.
  • The fix uses four steps: give agents a real reference standard (e.g., screenshots of excellent work), split work into independently judged pieces, assign each piece a fresh-context critic to compare against the reference, and iterate until the result wins or plateaus.
  • A single 3-paragraph prompt using this method produced a playable Call of Duty-style shooter game that got over 20 million views online.
  • Key limitation: an independent critic can have wrong preferences, and beating a reference doesn't prove the work actually achieves its real goal—humans still must choose the standard and validate usefulness.
