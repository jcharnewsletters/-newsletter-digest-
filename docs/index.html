37signals Abandons Hand-Written Code for AI-Generated Development

  • Ruby on Rails creator David Heinemeier Hansson announced his company 37signals, known for software craftsmanship, will no longer write code by hand, relying instead on AI agents.
  • AI agents handle initial coding tasks; when they fail (as happened with Basecamp 5 pull requests), engineers intervene only to fix the underlying workflow rather than the code itself.
  • The repair cycle: agent drafts code → human reviews → human identifies failure cause → human adjusts workflow → agent retries on similar future tasks; skipping this step causes architectural problems to accumulate.
  • Only five of dozens of Rails World attendees claimed to still write code manually every week, reflecting broader industry shift toward AI-native development.

TLDR (Tech) Companies are now paying top-market salaries for engineers who build AI-native products or integrate AI into systems, not for hand-coding skills, reigniting debate about whether AI reduces coding work or elevates it to architectural roles.

Google's Project Suncatcher: Orbital AI Chips Launch and Pass First Tests

  • Google launched a satellite carrying AI chips (TPUs, or tensor processing units—specialized hardware for AI computation) into orbit via SpaceX Falcon 9, testing AI in space.
  • Chips run in short 15-minute work bursts followed by cooling breaks, since vacuum lacks air or water to dissipate heat the way Earth-based data centers do.
  • This is a proof-of-concept test of radiation and thermal tolerance, not a functional data center; Google calls it a minimal test of hardware survival.

  • Google's team expects orbital sites to remain niche due to cost and complexity, not a replacement for terrestrial data centers.
