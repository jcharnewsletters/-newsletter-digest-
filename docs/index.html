OpenAI's new Decisions API cuts costs by routing simple choices to cheaper models

  • The Decisions API lets AI models pick from a fixed list of answers (e.g., routing a support ticket to billing, technical, account, or sales) instead of generating free-form text, avoiding JSON-parsing failures.
  • It can route simple requests to cheaper models like Luna ($0.10 per million tokens) instead of the priciest model Astra ($10 per million tokens)—a 100x cost gap that also applies to output pricing ($0.50 vs $50 per million tokens).
  • In AI agent systems (programs that take multi-step autonomous actions), the API can handle routine 'what's next' decisions, freeing expensive reasoning models to focus on actual planning.
  • Best suited for known-answer scenarios (yes/no, route to team, approve/deny); unknown-answer tasks like root-cause research still require a full LLM (large language model).
  • Currently in limited preview; broader release and pricing/latency benchmarks against Structured Outputs (a method for forcing model output into fixed formats) are expected soon.
