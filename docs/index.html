  • A vulnerability hidden in PHP code (a widely used web programming language) for over a decade allows hackers to take full control of web servers without passwords, affecting WordPress, Drupal, Joomla, and roughly 70% of all websites globally.
  • Cloudflare blocked thousands of exploitation attempts within 10 hours before public disclosure, rising to millions within 2 hours, forcing some government and critical-infrastructure sites offline.
  • Frontier AI models (advanced machine-learning systems trained on vast datasets) helped discover the flaw; researchers at Wiz (recently acquired by Alphabet for $32 billion) coordinated patches with PHP, OpenAI, and WordPress before the public announcement.
  • Risk remains elevated because AI tools can reverse-engineer patches into working exploits faster than defenders can deploy fixes, raising fears about automated cyber warfare targeting zero-day vulnerabilities (previously unknown security flaws).
